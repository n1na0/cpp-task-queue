# Лабораторная C++: Очередь задач (Task Queue)

Реализация очереди с приоритетом на основе двоичной кучи и полиморфизма.

## Что реализовано:
- Абстрактный класс `Task` с чисто виртуальной функцией `execute()`.
- 3 наследника: `PrintTask`, `MathTask`, `DownloadTask`.
- Своя реализация двоичной кучи (максимальная куча).
- Методы `push` (добавить с приоритетом) и `pop` (выполнить самую приоритетную).
